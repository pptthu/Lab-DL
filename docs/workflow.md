# Workflow (lecturer's vibe-coding method)

**Define -> Design -> Break down -> Build MVP -> Implement -> Test -> Refactor -> Commit -> Document**

Six principles: (1) understand the problem first; (2) plan before implementing: split into modules and milestones; (3) small prompts, small changes: one task per prompt; (4) run and verify every change; (5) AI is untrusted: verify every output; (6) explain your code.

Implementing a module: describe (detail plan) -> generate -> review -> run (smoke run, then normal run) -> test -> refactor -> commit.
Debug reports contain: expected behavior, actual behavior, error message, environment, relevant code, recent changes.
Oral exam: expect what / why / when / where / which / how questions about knowledge, code quality, correctness and results.

---

**Tiếng Việt**

Quy trình ở trên là của cô (vibe coding có kiểm soát): 6 nguyên tắc, vòng lặp implement từng module, báo lỗi đủ 6 mục, và vấn đáp theo what/why/when/where/which/how. Mỗi người phải giải thích được phần mình nộp, kể cả phần AI hỗ trợ.
