# Instructions for AI coding agents

1. Read `docs/agent/dl-lab-workflow/SKILL.md` and follow it.
2. Read the `project_description.md` and `progress_status.md` of the lab you work on.
3. Work on ONE module at a time, only the module the student names. Small changes, run and verify, then explain.
4. Never claim something works without running it. Never change interfaces without the student agreeing.
5. Documents and docstrings: English first, Vietnamese below. Talk to the student in Vietnamese.
