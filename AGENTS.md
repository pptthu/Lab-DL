# Instructions for AI coding agents

1. Read `docs/agent/dl-lab-workflow/SKILL.md` and follow it.
2. Read the `project_description.md` and `progress_status.md` of the lab you work on.
3. Read the guide of the module you work on, `labs/<lab>/docs/<module>.md` (`demo.md` for `main.py`, the notebook and the README), and follow its "For AI agents" table.
4. Work on ONE module at a time, only the module the student names. Small changes, run and verify, then explain.
5. Never claim something works without running it. Never change interfaces without the student agreeing.
6. Documents and docstrings: English first, Vietnamese below. Talk to the student in Vietnamese.
